# Structured judgment format repair

The original-objective assessor reads frozen files under a read-only grant. Once host read coverage is complete, a malformed JSON assessment now receives fixed, parser-specific schema feedback in the same session. No model verdict is accepted, task dispatched, or mission closed until a fresh valid assessment passes the original host validator. Real prompt or admission failures still end that assessor attempt with the original objective incomplete; there is no retry-count stop.

The frozen original-objective contract is an allowed evidence reference because the host requires the assessor to read it. This change does not alter closure checks or scientific acceptance. Synthetic tests cover malformed output followed by valid output, repeated malformed output, and a real admission boundary. No confidential task response or provider call is embedded in the tests.

An M07 round reviewer now repairs malformed JSON in its same independent read-only session against the same frozen snapshot. The builder operation is not replayed. Every bounded attempt is retained in task-private files, while the final valid verdict keeps the canonical archive path. A reviewer prompt failure retains the received builder operation and ends without claiming a valid verdict.

M04 now repairs an explicitly malformed knowledge-proposals JSON block before any store submission or merge, after required evidence-read proof. A missing proposal block remains a valid no-proposal choice. A parsed proposal with structurally invalid operations still goes through the existing one-shot store validator; format repair cannot erase its receipt. The M08 disposition path is unchanged.

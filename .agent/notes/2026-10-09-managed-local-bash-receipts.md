# Managed local bash execution receipts

This change gives Pi execution sessions a host-written receipt for each bash tool call. The runner persists a prepared record before entering the local bash backend, then records spawn attempt, PID and available precise process identity, process group, numeric shell exit or signal, and the final Pi tool outcome. Each record binds the exact Pi tool call ID, session ID, working directory and SHA-256 of the shell command without retaining the command text. A private, synced replacement file preserves the last complete transition after process failure. The task tool log points to the receipt.

The POSIX backend uses Pi's selected shell. It captures stdout and stderr through an unlinked host file, streams observed bytes to Pi while the command runs, and drains the exact byte length visible when the shell exits. A detached child can write later, so the receipt retains `remoteOrDetachedEffects: "unknown"` even when no same-group process is observed. Numeric shell exit is not proof that remote operations or filesystem side effects succeeded. Windows continues through Pi's local bash backend and records available terminal facts without inventing PID or process-group evidence. The current same-UID host arrangement is not an OS isolation or tamper-proof boundary.

The recovery reader accepts only a private regular receipt file with a strict canonical schema and session binding. An incomplete prepared/spawn-attempted record remains unknown; a temporary file from an interrupted replacement is not a terminal receipt. This increment provides tool-level facts for recovery. It does not itself settle an M07 task-level external operation or automatically replay a process.

Offline verification: TypeScript typecheck passed. The focused Pi runner suite passed 60 tests, including actual shell zero and nonzero exits, an aborted pre-spawn call, a write-ahead crash window, detached output, command hashing and identity binding, and reader rejection of forged, linked or publicly readable receipts. No model or network calls were made.

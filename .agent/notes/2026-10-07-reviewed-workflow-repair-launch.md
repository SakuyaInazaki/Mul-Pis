# Reviewed workflow repair launch

- Added a private operator-reviewed release plan for authenticated terminal workflow repairs. The review binds the exact carried checkpoint, pending action, repair-state receipt and a different live source commit/tree with successful source CI.
- Plan input is an exact-schema mode-0600 regular file outside the repository. Its structured code and offline regression references are checked against the exact tested source, with stage/failure relevance and an actual relevant source change. This does not introduce a source-file hash manifest or certify scientific success.
- The host verifier brands the immutable plan in memory. The supervisor requires that brand and the matching existing fresh-work launch contract; old sessions, stores and unknown effects gain no replay authority.
- Private reservation identity now includes the reviewed plan and exact replacement source/tree/CI. Missing or stale plans stay closed; repeated matching plans retain durable dispatch idempotency.
- The bridge accepts the optional private plan argument and retains the existing constant-message public Git control descriptor. Review records, task details and repair metadata stay private.
- Focused offline coverage exercises both repair stages, missing/forged/stale plans, source and test relevance, receipt binding, unknown effects, private-file boundaries, one reservation and repeat/uncertain-delivery behavior. No remote mutation, provider call or active-run change is part of this batch.

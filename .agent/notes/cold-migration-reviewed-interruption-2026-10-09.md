# Reviewed cold migration of interrupted local dispatch

This isolated implementation adds a V5 host checkpoint review for a legacy interrupted local dispatch transferred to another host. A trusted host callback must authenticate the retained original-host terminal and effect-census observation, its platform message references and times, the exact old owner/attempt/checkpoint, the pre-migration archive digest, and the finite one-shot launch and no-observed-restarter boundary. User-supplied request bytes alone are not authentication. The successor is published under the existing exclusive writer lock with a single atomic attempt-directory rename. The old provider usage, M07/M04 records, and task outcome remain retained; only fresh follow-up work is authorized.

The legacy effect review still requires the full retained workspace/tool/provider census. Cross-host review accepts only the original-host reviewed tool-and-process census; a negative process-group probe on the new host cannot establish old-host settlement. The observation file is canonical JSON with a trailing newline. Its terminal record retains the observed exit code, and its workspace-census hash is identified separately from the original-host platform message. The archive is hashed as a stream without a size ceiling. The review records its same-UID trust scope and does not prove OS noninterference or a permanent lock against copies. Existing checkpoint versions and same-host review schemas remain unchanged. Default mission continuation recognizes the V5 reviewed running MISSION as represented and starts a fresh assessment. No real mission or provider operation was run in this batch.

# Default objective evidence context, 2026-10-12

The default local mission retained each bounded M07 feedback part and each prior host capability and evaluator task contract in the assessor's frozen evidence directory. Before this change, every older capability and task contract was treated as required, so every new assessment had to read them again. The prompt also repeated the filename and line count of every retrievable prior feedback part, including files unrelated to the next decision. Over a long mission this made fresh prompts and mandatory reading grow with history.

Older capability observations and task contracts are now retrievable on demand. The current assessment's capability observation and current declared task contract stay required; the host still verifies their exact bytes before dispatch and on recovery. Prior M07 feedback remains frozen and readable, with the latest rejected or failed task's feedback still required for repair. The assessor can use the existing `material_list` tool to discover older frozen files, then `objective_evidence_read` to inspect relevant content. A filename alone gives no evidence credit; cited whole files and spans still need current-session reads.

The local longevity regression now checks that older capability and feedback files remain available while their names do not accumulate in the prompt, and it withholds old capability reads to verify they are no longer mandatory. The current capability remains mandatory. No historical evidence was removed and no new storage or locator format was introduced.

Initial isolation with a canonical temporary directory passed the longevity regression. After the companion mission-entry path repair, it also passed under the normal macOS temporary directory. The objective, evaluator, and longevity tests passed together (133 tests); the current-task-contract checks also passed in the existing evaluator tests. The separate dependency compatibility fixes restored typecheck. These are offline tests, not measured research gains. Historical checkpoint size and physical evidence-copy growth are outside this prompt cleanup.

# Private transport-cause continuation

The host can now retain a narrow, optional transport-diagnostic census inside the authenticated encrypted continuation bundle. It binds each saved diagnostic row to an unreceived unknown request in the exact accounting audit and binds each source entry to its accounting ancestry and prior carry digest. Earlier entries are append-only. A missing key remains valid for historical carries; no earlier HTTP response is retrospectively classified.

The carry includes only fixed transport states, HTTP status, byte count, abort source, and allowlisted provider/network error enums. It excludes prompt content, response body, free-form errors, provider request identifiers, and parameter values. An unavailable cause stays explicitly unavailable. The model may see a validated read-only projection for replanning, but this does not settle an unknown charge, reconcile an operation, resume an old session, or establish scientific acceptance.

Offline tests cover a valid encrypted round-trip, an unavailable observation, exact audit-ID and source binding, duplicate diagnostics, rejection of raw or unallowlisted values, and preservation when the next run has no new unknown transport. Existing no-diagnostic carries remain readable. No paid model call or publication was made for this change.

# Manual public M01 environment check

Added a separate generic DeepSeek M01 smoke entry and Actions workflow. It supports manual dispatch and one publish-time push guarded by exact repository, actor, branch, head-commit marker and first run attempt; the temporary push trigger must be removed after that one check. The entry exercises the real Mul-Pis stage service and Pi session runner, while enforcing one tool-free provider request, capped input/output, isolated model configuration and a conservative planning ceiling. It checks the Pi usage sidecar for one complete priced assistant event, emitting only whitelisted observed counts and SDK-estimated cost before removing the temporary workspace. The offline tests cover the budget invariant, current model resolution, missing-key fail-closed behavior, usage completeness and output redaction. This change itself neither runs a model nor transfers any private lab input. The result is a prerequisite check only; a private lab run remains unsupported until a separate private-I/O and whole-campaign budget design is reviewed.

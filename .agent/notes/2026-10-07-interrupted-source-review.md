# Private interrupted source review capability

Added a host-side reader for an operator-approved, fresh-only capability after a terminal executed run without a carry. The reader requires a private mode-0600 receipt outside the checkout and binds it to the authenticated interrupted run, its immutable source tree, the preceding authenticated checkpoint, and the opaque result artifact. The host resolves role-tagged code and test references from that exact source commit. Reference resolution does not decide whether the cited code is safe; the operator owns that semantic judgment.

The capability has fixed confined local tools, read-only model sessions, fresh workspace and store, no session resumption, fixed encrypted output and provider routing, and no replay or adoption of the opaque old result. Every receipt must also cite source and tests for host execution confinement, covering any compiler, interpreter, validator, or generated artifact execution reached by the interrupted source. This is a generic review role, with no fixed source filename or workload language. Review references may include the campaign driver, tool factory, Python transport, workflow, and associated TypeScript and Python tests. Their paths and anchors show the provenance of the operator's review, not proof of code semantics. The reader returns only a frozen process-local brand and receipt digest for host consumption. It does not store task text or credentials.

Offline synthetic tests cover accepted receipts, forged clones, unrelated source or artifact identities, missing evidence, weakened grants, and unsafe file permissions. No provider calls or external writes were made.

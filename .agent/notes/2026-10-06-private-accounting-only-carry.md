# Make private transport accounting observational

The private DeepSeek transport no longer uses a CNY total, prior commitment, SDK tariff, or remaining-balance calculation to admit a provider request. It still verifies the model, endpoint, actual provider output maximum, request payload, confined tool authority and usage correspondence. Native CNY estimates are recorded only when the live currency and price profile is verified at the request; otherwise the request keeps an explicit unpriced observation with raw SDK usage. Missing or failed replies retain uncertain observations. Output-length and real tool/operation-integrity failures remain separate from fee uncertainty.

The private driver now attempts the read-only billing-profile check but records unavailable pricing as unknown. It uses accounting-only transport and a versioned encrypted carry, preserving authenticated historical commitments without treating them as invoices or a new-run fee ceiling. The existing signed seed authenticates the old carry before the host mints a v3 transition with a separate historical commitment bucket; no new secret or new signed seed is required. Old signed seed and carry bytes keep their original validation meaning. Current-run activation requires manual workflow dispatch; historical push runs remain readable in ancestry. The public M01 smoke independently stopped using its old 2.1 CNY planning ceiling; its change is recorded separately.

No paid provider request was issued during this change. The private Actions launch is manual-only and continues to require explicit authorization. Focused tests use synthetic providers and artifacts. Typecheck, diff check and 115 offline fee-removal focused tests passed after integration; the root agent owns the complete repository suite.

# 算子优化工作流公共变更记录（2026-10-18）

本批将算子优化研究中已确认的执行、检索和交接缺口接入现有 M07/M04 工作流。原目标、成功标准、任务契约及 M04 科学采用权保持不变；通用核心没有加入固定搜索轮数、硬件规则或自动判定优化路线。此记录概述当前公共源码变更，不包含原实验、账户或私有适配材料。

- `src/m07/` 增加受信宿主候选执行与冻结回执、同会话候选核验、跨任务候选读取和按工作对象及测量口径呈现的搜索反馈。未决且已有 ID 的外部操作沿原 ID 查询；身份未知时阻止重交并交由现有宿主对账。目标完成仍逐项核对原成功标准、当前有效的已接受证据和宿主实际提供的核验；已审查失败探索保留为历史，不额外改写原目标要求。
- `src/runner/` 收紧执行工作目录、工具和只读证据范围，补齐字符分页及实际返回覆盖记录。`src/knowledge/` 与 `src/stages/m04.ts` 在原发布快照和实时限制内提供分页知识发现、正文及已登记来源原件补读，并区分索引曝光、实际阅读和 M04 采用。知识合并的必要依赖传播与一般论证关联分开，历史限制仍保留；解除限制可按既有来源精确选择。
- `src/pi/` 与 `terminal-console/src/console/` 接通当前 service、进程身份和只读执行树，分别显示候选观测、任务评审、原目标进度及知识回流。清理与当前控制器重复或冲突的旧终端影子入口；终端显示不代替评测、复核或采用。
- `extensions/local-operator.ts` 与对应后端、脚本提供宿主声明的编译、独立参考正确性、替换检查和成对计时入口，保留原始测量与独立 profiler 证据。已有 CPU 机制检查不等同于真实 GPU 设备验证，平台委托评测保持独立适配。
- `workflow/v1.0/` 的执行提示同步原目标、候选证据和知识采用边界；`src/improvement/` 对无法忠实重放的提示投影作显式区分，并按实际正文读取范围评估知识回流。
- 更新既有离线回归，覆盖候选冻结和恢复、原目标证据、分支放弃、知识分页与权限、测量归属及终端投影。发布验证 `npm run typecheck` 通过；`npm test` 共 439 项，435 通过、零失败、4 项 Linux 专用检查因当前系统条件跳过。最终暂存差异、公开文件清单与认证材料排除审查通过。

这些工程检查及有限的真实任务只读观察只证明相应链路可以保存和传递证据，不能证明搜索策略优于先前版本、知识复用带来因果收益，或原目标已经达成。宿主任务仍需提供自己的设备、正确性、计时和最终验收契约；候选结果、模型判断与知识记录不会自动成为科学结论。进程恢复只沿已有受控交接与原操作对账路径进行，不承诺崩溃会话重放或通用异步调度。

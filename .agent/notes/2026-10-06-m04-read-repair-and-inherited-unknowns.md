# M04 read repair and inherited unknowns

The M04 research session now receives host-computed missing-line feedback for required frozen M07 evidence while that same read-only session is still live. A provisional or malformed response cannot reach knowledge proposal parsing or merge until the complete returned-range check passes. Feedback points to the next missing range rather than imposing a turn or range-count stop; an actual read-tool error remains an explicit failure. Synthetic tests cover partial and unchanged reads followed by complete reads, and verify that premature proposals are ignored.

The private restart effect classifier now accepts an omitted empty unresolved-operation list for a settled new goal, while still requiring explicit recorded unknown-operation IDs when unknown operations exist. It also carries attestations for unknown operations introduced by reviewed ancestors: each addition must be monotonic and tied to its previously bound goal and authenticated quarantine receipt. An abandoned no-goal claim consumes a reservation but no goal binding, so a later ancestor cannot fabricate an operation from that gap. The final attestation set must exactly equal the full current quarantine set. Synthetic tests cover a later settled goal inheriting an earlier unknown, a no-goal interval followed by new work, and reject shaved or unbound refs.

These changes preserve historical unknown billing and operation quarantine. A controller-accepted M07 task is still not an M04-adopted lesson or a selected mission replacement. No paid model calls or public private-input publication were made for this repair.

# 终端控制台独立保存

为单独审阅和同步终端工作流控制台，在仓库根目录新增 `terminal-console/`。目录按原有相对路径保存终端界面、宿主、Pi 桥接、遥测、相关测试及设计说明；对基线现有文件的变动集中保存在一份 `integration.patch`。补丁的基线是 `4b12d32`，包含旧 dashboard 退役、入口与共享控制接口的对应变化。目录中的 README 明确说明它尚未与当前算子修复分支集成，共享 M07 与 Pi 文件需在正式合入前逐项复核。

仅从原工作区复制所需源码、测试和设计文件；未复制研究记录、私有目录、认证材料或第三方代码。用独立临时 Git 索引确认补丁可在指定基线上应用，并核对新增文件与来源字节一致。本批未运行测试、未修改活动研究运行、未暂存或提交文件。

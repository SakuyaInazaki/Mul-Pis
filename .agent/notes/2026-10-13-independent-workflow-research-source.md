# Independent workflow research source

Workflow comparison arms already used isolated workspaces, but the improver sessions, candidates and active research pointer belonged to the workspace that invoked the campaign. A new explicit `workflow prepare --plan --output` command and `prepareWorkflowSource` service entry prepare that owning workspace as an independent copy before existing run or calibration calls.

Preparation reads the source without taking a mutation lock or changing its files. It preserves the knowledge store identity, published and historical records, negative limits, method versions and ancestry, active policy, selected development and protected inputs, formal M04 and selected historical feedback. Every copied M04 checkpoint binding is made readable locally; producer sessions are omitted. Optional development MetaEpisodes retain their controller provenance. Raw reports and evidence remain byte preserving; only derived control paths and the credential-free configuration are rewritten. Source file and control-state comparisons detect changes during preparation. A preparation that fails retains its partial destination for inspection and requires a new destination on retry.

Offline regressions exercise actual existing workflow methods through a fake runner: historical and current M04 records use distinct checkpoints; production knowledge, model configuration and cases change after preparation; the independent source still runs improver inspection, proposal, development comparison, protected admission and local activation. Every production file is compared before and after preparation and research. Additional coverage follows selected MetaEpisodes through the CLI and rejects unfinished merges, unresolved external experience and protected/common input overlap. Read-only review identified the second-checkpoint provenance issue, which was repaired and covered before release.

Validation: typecheck and 40 workflow handoff tests pass. The final full offline suite completed with 1,612 tests: 1,596 passed, zero failed and 16 existing platform or local-fixture skips. The initial full run exposed three synthetic upload timeouts caused by its unisolated disk probe; the accompanying test-isolation note records that repair. The final suite includes the repaired observer fixtures. No real model or network is called by these regressions; the active experiment process remains on its original loaded code.

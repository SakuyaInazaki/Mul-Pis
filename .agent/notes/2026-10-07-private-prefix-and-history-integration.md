# Incremental control and retrievable history integration

The private campaign now writes a locally atomic, authenticated nonterminal control prefix before a model transport, after a received provider response, and after host checkpoint updates. It records the current request accounting observation, known session grants, persisted M07 controller rows, and the latest available original-objective checkpoint. The prefix is explicitly incomplete; a later unobserved suffix remains unknown. The existing encrypted-result wrapper carries the file, and the existing mission-carry artifact upload may carry its encrypted bytes when a final carry is absent. No provider prompt, key, or plaintext research artifact enters public output.

The assessor now distinguishes evidence that must be read completely in the current session from retained historical evidence that can be fetched by exact ranges. Original inputs, current selected evidence, and the required history locator remain mandatory. A host-generated episode locator names untrusted historical run/task and artifact identities with exact part and line locations; citing unread raw history still fails host validation. Older grounded issue records are kept in frozen indexed parts and merged by the host, allowing a new model response to focus on new issues or evidenced resolutions. The original goal, accepted selection, and open-ended global-optimality guard remain unchanged.

Focused offline tests cover ordered prefix writes before fake HTTP, context retry separation, atomic local prefixes, bounded lossless history parts and catalog lookup, mandatory evidence reads, and unread cited-range rejection. A killed runner can still lose work after its last stored prefix, and artifact upload depends on the platform executing the existing final wrapper. Prefix observations do not certify final billing or scientific acceptance.

The current assessor issue index is one bounded physical file. A sufficiently large set of historical issue locators can exceed that file's transport limit; the driver must report that storage boundary as incomplete and preserve earlier authenticated state. A local prefix and the carried checkpoint also have finite byte bounds. The prefix records accounting and controller observations, but the successor currently treats the entire interrupted suffix as UNKNOWN and does not use the prefix to reduce a fee hold or adopt newly selected research. A future closed-selection snapshot would need the selected artifact bytes and the ordinary accepted M07, complete M04, selected-transition, and current verification proofs before any scientific promotion.

If a safely resumable interruption has an unusable prefix, the host bridge keeps its static decode stage and reason in the mode-0600 private preparation result even when it prepares the fresh-work request. The public control descriptor and launch decision do not include or depend on that optional diagnostic.

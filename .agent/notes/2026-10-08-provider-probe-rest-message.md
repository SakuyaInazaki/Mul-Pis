# Provider probe commit message normalization

A real read-only availability probe completed and its encrypted result was reviewed locally. Host preparation then stopped before any research dispatch because GitHub's commit JSON omitted the request message's single final line feed. The repository commit and its fixed terminal, nonce, source and tree bindings were otherwise unchanged. The generic refusal also obscured the verifier's static private cause.

The host verifier now accepts only the canonical fixed message with its final line feed or the same bytes without that one final line feed. It does not trim whitespace or accept changed trailers, CRLF or extra text. The private host preparation diagnostic retains the verifier's fixed cause code, stage and message-check label; public descriptors and error output remain generic. This batch does not modify a carry, fee observation, selected result, journal reservation, provider credential, or scientific task.

Synthetic tests cover the GitHub REST message form and malformed message variants. No availability probe or research request was launched by this code change.

# Private provider reason and request preflight

The private Pi transport records the actual bounded provider error code, type, message, parameter and present numeric limit fields after credential redaction. This detail appears only in the encrypted private result status. The authenticated continuation census still stores a fixed reason class and never imports the provider message or private request text. Missing or oversized error JSON remains explicitly unavailable; no past error reason is reconstructed.

Before reserving or issuing a DeepSeek request, the runner validates the final serialized message sequence and applicable thinking and tool-call requirements. A rejected attempted payload records a fixed violation code. A separate whole-prompt no-request proof requires zero earlier reservations on its exact lease; any earlier unreceived request remains UNKNOWN. The M07 controller records a private no-request receipt, and the archive carries only the validated static violation and message index. An incomplete checkpoint selects request-contract repair from that host evidence. The check does not rewrite prompt history, fabricate reasoning or tool results, silently reduce the output bound, or decide a scientific outcome.

Live objective admissions also reject fee, call-count, elapsed-time and unchanged-round stops as new control reasons. Historical checkpoint values remain decodable. Branded legacy quota errors cannot turn an issued M07 operation into a certified local stop; the operation stays UNKNOWN unless a real response disposition is proven. Tests use synthetic interrupted runs and actual physical output boundaries to verify the current control behavior.

Checkpoint salvage now writes an incomplete current continuation when it encounters a retired historical time stop. A focused regression keeps the old checkpoint bytes separately readable and verifies the new active checkpoint carries a fresh-work action rather than reviving that old time rule. Explicit cancellation still produces a distinct current stop.

# Remove local execution-time and retry stop quotas

This change removes the Pi stage runner's default one-hour prompt and ten-minute silent-progress aborts, and the main Pi extension's ten-minute inactivity abort. Progress heartbeat and explicit host cancellation remain. The existing stage AbortSignal is now passed to M05 HTTP, Python/browser, and PDF subprocess operations, so an explicit stop is distinct from an idle network failure. Explicit watchdog settings remain for callers that intentionally request them. An identical stage failure is still recorded diagnostically but no longer blocks the next attempt after two repeats.

M05's interactive-browser wrapper no longer applies a ten-minute subprocess kill or a 40/200-step quota. The browser-use adapter now drives individual steps until the agent reports done, preserving startup, initial actions, artifact capture, usage summary, and cleanup. It checks the required SDK methods before opening a browser; an incompatible installation returns a capability error rather than quietly falling back to a finite step count. Live browser/provider behavior was not exercised because the local browser-use package and paid credentials were unavailable. M05 browser artifact capture no longer stops after 20 changed page states or 12 screenshots; byte ceilings for HTML, Markdown, screenshots, and registered downloads remain, with an explicit omission warning when reached. The M05 optional PDF partial-page argument remains a user-requested range, without silently clamping it at 500 pages.

Local Python and poppler subprocesses are no longer killed solely for elapsed processing time. The later scope clarification keeps task-specific experiment adapters outside this repair batch. The uncommitted CSR CPU/protocol policy edits were withdrawn; the workflow must distinguish externally reported execution or communication failures from scientific acceptance without claiming control over an arbitrary adapter. Finite HTTP connection/byte-idle timeouts remain transport-fault detection, not overall research deadlines. The shared HTTP helper now resets its idle timer on each received chunk, waits for the body as well as headers, and enforces 20 MB text/JSON and 250 MB download byte ceilings. This keeps a progressing slow transfer alive while detecting a stalled connection and retaining file-size protection.

Offline checks: actual module imports for the M05 fetch tools and Pi extension; targeted TypeScript tests for stage retry, explicit opt-in prompt watchdog, default no-deadline behavior, M05 artifacts, and the CSR checker; Python synthetic browser-adapter tests with 501 steps, 25 captured page states/screenshots, and failure/cancel cleanup; synthetic HTTP tests covering slow progress, body silence, and response-size rejection. Repository-wide typecheck and tests require integration with concurrent workflow-limit changes before they can be claimed to pass.

# RSI 运行契约修复（2026-09-24）

本批依据本地附包的只读复现与当前仓库代码核对，修复三处确定性冲突；附包的 A/B/C 与 22 条验收仍为建议，不能当作已通过结果。

- `prepareModelRequest` 在请求前一次性组装系统提示与消息的有界封套，分开记录原始 UTF-8 字节、序列化 payload 的保守字节上限、输入 token 的保守预留和请求后 provider usage。实际 dispatch 使用同一个准备对象。旧固定 8192 额外预留与示例 8192 上限的必然冲突已移除；文档 H 示例调到 20000 输入上限并重算相关阶段额度。SDK 最终 payload 仍由严格边界检查。
- `SharedBudget` 子 lease 可在已结算后关闭并封存自身执行时间；未结算、未知、超时、未关闭子 lease 不得关闭；关闭后不能再次执行。元比较各搜索臂完成即关闭，根 campaign 继续按真实时间计时。
- H 开发评价将支持结论、按当前公开测量与允许动作合理未知、被否定结论、过早停止及执行不完整分开记录。合理未知可保留候选的科学有效性，但不算完整解题或 G 准入收益。
- 增加无模型回归：文档 H 计划与完整假种子可走到第一条请求；请求编译对象与 fake dispatch 一致；时钟关闭、未知费用阻断；不可辨识开发任务的合理停止。

本批未进行付费模型实验、独立 H/I 收益比较或真实跨代重入；这些仍不能声称为 L5 证据。私有案例、日志和费用不进入公开材料。未提交或推送。

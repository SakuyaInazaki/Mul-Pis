# Fixed source loading and M07 attempt binding

- Added an optional `loadedSource` claim to run descriptors for explicitly prepared fixed-source launches. Historical descriptors without this field retain their existing interpretation.
- Added host preparation and launch scripts. Preparation exports only the runtime source, extension, workflow text, Python adapters and package metadata at an explicit full commit into a new read-only tree; existing installed dependencies are linked without copying or changing their permissions. The launcher fixes the execution workspace, source entrypoint and revision before creating a new process.
- Added startup verification that the imported runtime module and entrypoint are inside the selected source tree, the read-only preparation receipt names that tree and a full commit, and exported source directories remain read-only. Existing dependency links are outside this check.
- Wired the check into the CLI and Pi extension. The explicit launcher performs the hard check before starting Pi because this Pi SDK reports extension `session_start` errors and then continues. The extension repeats the check for its own state; it is not the fail-closed entry boundary. M07 begin records the verified loaded source in its attempt; fresh recovery and ordinary continuation check the current attempt's claim against the code loaded by that process. Recovery may bind a different verified commit while the frozen goal and method obligations stay unchanged.
- M07 delegate and review now check the active attempt's source proof before advancing it. A different loaded version cannot create tasks or scientific review under an older running attempt; status and host repair remain available. Attempts predating the proof retain their former compatibility.
- Added offline tests for a false descriptor revision, missing proof, writable receipt, and actual M07 begin/recovery across two prepared source commits while preserving the frozen goal. Real subprocess coverage keeps A alive while its development checkout changes to B, checks a later import still comes from A, then launches B even with an inherited A environment. A false source descriptor and a missing descriptor for explicit recovery are rejected before the target starts.

The M07 cross-version test proves that B cannot delegate or review A's running attempt, performs no model call or task write, then delegates after explicit B recovery.

# 新会话 200k compact（2026-10-12）

新建普通 Pi 工作流会话采用 200,000 token 自动 compact 阈值，沿用 Pi 在请求和工具批次之间的原生检查及摘要路径。保留约 20,000 token 近期内容和原生 16,384 token reserve 对应的摘要预算，不改模型上下文窗口或输出上限。策略随新会话记录，恢复已有新策略会话时复用；无策略记录的历史会话继续使用原设置，受控 strictRequest 会话继续禁用 compact。

Pi 资源重载会刷新设置，因此会话级 override 在资源重载后应用。内置压缩扩展仅调整本次摘要准备对象，避免提早触发阈值顺带放大摘要输出预算。普通请求代理保留 Pi 显式指定的摘要输出预算；只有未指定时才使用模型最大输出额度。

本地私有启动器为后续主会话创建独立 profile 并配置相同策略。正在运行的进程、profile、任务内容及原始知识记录保持原样。本批只改工作流会话机制、状态展示说明和离线测试。

验证：TypeScript typecheck、启动器语法检查和 `git diff --check` 通过。知识库、Pi runner、请求契约、会计记录、工具流、扩展、持续执行与 M07 分支的定向离线回归通过；两项 Linux 进程夹具在 macOS 按原设置跳过。原生 Pi 测试确认工具循环超过 200k 后完成摘要并续执行，摘要请求仍使用 13,107 token 上限。已有恢复测试覆盖新策略持久化和历史会话保持原样；删除重复的内存策略单元测试，保留调用链与恢复行为验证。

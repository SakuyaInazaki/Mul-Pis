# 本地工作流面板

- 新增研究工作流面板的安全状态快照、短时心跳记录、只读 HTTP 服务、CLI 和静态前端。
- 工作区选择限于启动时显式给出的单个目录，或项目 `workspaces/` 下的直接子目录；浏览器只能用不透明 ID 选择已登记工作区。
- 面板区分活动、待命、归档和未知状态；旧的 `running` 记录没有新鲜心跳时保持未知，不伪装成实时运行。
- API 不提供绝对路径、原始会话文本、prompt、密钥、研究产物正文、任意文件读取或命令入口。
- 本地服务仅绑定回环地址，并校验 Host、Origin、只读方法、静态路径和响应大小；前端轮询失败时明确显示断线或陈旧状态。
- 状态读取前仅核验面板实际消费的 run、goal、telemetry 与 spec 元数据路径；符号链接或真实路径越出工作区时拒绝快照，不扫描研究产物和会话正文。
- 按用户纠正后的表达，前端收敛为单张主链与可选反馈回环图；规则连线不冒充实际执行关系。点击阶段进入单阶段聚焦画布，同时展开全部运行和关联 agent，节点详情按需打开，不再显示侧栏、统计区或常驻工具栏。
- 修正空状态覆盖、子节点点击被拖拽重绘吞掉、详情在关闭后被轮询重开、阶段展开重叠，以及断线缓存继续显示活动文字等交互问题。
- 全套 117 项测试通过，其中包括服务元数据符号链接回归；TypeScript 检查与差异格式检查也通过。
- 独立浏览器验收覆盖桌面与窄屏主链、单阶段聚焦、全部展开节点、拖拽与普通点击区分、详情、缩放和平移、轮询后位置稳定、详情随快照更新且关闭后不重开、断线时活动缓存降为未知而归档状态保持不变。截图保存在本地私有验收目录，不进入公开材料。
- 对真实 `xpuoj-105` 工作区完成只读快照，得到 39 个节点与 23 条实际成员边；直接比较前后 `run.json` 文件字节内容未发生变化。
- 发布前模拟了已跟踪文件与全部未忽略未跟踪文件的公开清单；确认 `third_party/`、`resources/`、`workspaces/`、`.agent/private/`、嵌套 Git 元数据与本地凭据均不在发布候选中。公开 notes 中的内部题目编号和提交引用已改为只指向 ignored 私有记录；候选文件未发现机器绝对路径、内嵌密钥或原始聊天记录。
- 清理面板中的实现说明与操作提示：移除路径规则详情、状态字段依据、拖拽缩放提示和阶段交互说明；保留阶段、运行、Agent、模型、业务状态与时间等实际元数据，以及连接错误反馈。

# 改进外环测量与机制准入变更

- 将预算策略历史采样改为仅使用 M07 实际投影事件的 UTF-16 长度、调用边界和交付状态；旧阶段输入不再作为可晋级证据。
- 将投影重放作为候选筛选；晋级需要调用者显式预算、准入案例和控制器执行的成对无工具机制实验。开发案例、缺失用量、零触发、预算耗尽、超时与不充分证据均不晋级。
- 增加有界串行 campaign、可证伪假设、历史结果消费、重复候选检测、失败及资源记录；提供方法包导出与人工显式导入，导入来源标为外部人工且未经本地独立重验。
- 保持活动指针为唯一晋级提交依据，并保留跨进程锁、旧目标策略冻结与回退。
- 机制准入只检查预注册的结构化答案、必要证据范围与 SDK 估算成本，不声称完整科研工作流收益或实际账单。
- 离线目标测试覆盖 M07 投影采样、筛选、接受、拒绝、不充分、预算、超时、跨工作区绑定及回退；不调用网络或真实模型。
- 准入案例须显式标为 admission，并至少进行两次偶数重复；两臂顺序交替。所有注册案例均执行，任一硬检查失败或任一配对成本上升均不能晋级。结果只表示局部机制案例的预注册机械检查通过，不代表统计显著性。
- 历史消费输入含前轮可证伪假设、策略参数、失败门禁和粗粒度失败类别；同一冻结实验义务内拒绝重复候选，有新增观测事件时可重新评价。
- 重新覆盖旧版底层回归：锁、CAS、指针提交中断、策略封闭校验、跨代覆盖率、未重放 cap，以及回退不解除知识限制。
- 跨工作区绑定的版本读取另以新 Node 进程验证；这只证明新进程装载方法版本，不证明跨新题科研收益。

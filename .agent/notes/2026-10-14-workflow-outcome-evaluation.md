# Source-arm outcome evaluation boundary

Added an opt-in v2 case contract for source-arm experiments. Its visible projection contains the M07 goal, one task, a fixed mechanical report-delivery check, and paths of required source inputs. Private ground truth remains in the controller process. The source arm freezes those inputs as review artifacts; its controller review checks only report delivery. The existing v1 literal-check protocol and records remain readable and executable.

The controller's trusted result evaluator reads the frozen M07 report, current M04 run and transaction, published knowledge pointer, and actual returned text ranges or artifact-specific inline text. It reports execution completeness separately from checked semantic results and retains observed use. A complete but incorrect M04 knowledge decision is a quality failure; missing original-evidence reading blocks semantic scoring. Complete and indexed feedback statuses are accepted only with a settled M04 transaction and proved current-session evidence delivery. The initial candidate source comparison is restricted to the evidence handoff module, with fixed parent-side prepared-source verification; selected source verifier code is not imported by the parent.

Offline fake-session regression covers v1, v2 private-ground-truth isolation, an incorrect M04 outcome despite a correct M07 phrase, unread required evidence, indexed feedback with full reading, and rejection of a candidate edit to controller code. Typecheck and the directed source-arm test passed. This is mechanism verification, not a real-model research outcome or scientific benefit claim.

The first full offline suite exposed two legacy A/A partial-pair equality failures: when a workspace had no current knowledge snapshot, the new optional `knowledgeBeforeSnapshot` property existed as `undefined` in the in-memory arm receipt but disappeared from the JSON-persisted run. The same shape mismatch could affect `knowledgeAfterSnapshot`. Both fields are now assigned only when an actual snapshot ID exists. The complete `workflow-evidence-handoff.test.ts` file passed (40 tests), and TypeScript typecheck passed after the fix. The final full offline run passed: 1,642 tests, 1,626 passed, zero failed, 16 environment-specific skips. The final typecheck also passed.

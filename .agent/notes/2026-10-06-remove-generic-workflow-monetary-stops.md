# Remove generic workflow monetary stops

The generic research-method and M07 evidence-handoff paths no longer require a total SDK-estimated cost ceiling or use one to stop execution. Historical root and phase cost fields remain readable as display references, while provider calls, tokens, CPU/probes, observed cost, in-flight requests, and incomplete usage are still recorded. No artificial infinite numeric cap is serialized. Phase allocation still precedes campaign activity, and live request settlement remains a lifecycle check.

The controller now separates missing price-table cost from missing provider events. Complete scientific work can continue when only cost is unknown; missing provider events and incomplete M07/M04 tool-use evidence still block the relevant scientific workflow. Executor quality remains governed by registered scientific checks. The meta-efficiency protocol still requires complete measured search-cost evidence before claiming strict improvement. Development episodes and public projections label an incomplete cost as unknown rather than presenting a zero lower bound as a measured price.

Offline focused tests cover legacy cost references, no-cost plans, spent references, unknown cost continuation, in-flight handling, workflow usage, and incomplete meta-efficiency evidence. No real provider request, network test, payment, commit, or push was performed. The standalone mechanism-cost campaign and strict DeepSeek accounting are separate changes.

The subsequent obstruction audit removed an unrelated 8,000-character truncation of an already bounded M04 processing source. Its complete registered text is now pageable by offset, with length and UTF-8 byte metadata. The isolated workflow copy walks ordinary directory trees iteratively, regardless of depth, while still rejecting links, non-files and files over the existing 8 MiB bound. Inherited method and knowledge references no longer fail solely because their count exceeds the old 40/100 ceilings; exact identity, applicability, live limits, duplicates and bundle ancestry remain checked. Verification of necessary experience does not render a model-visible pack or impose its character window on inherited obligations.

Development-only MetaEpisodes now retain all registered feedback rows and observations. A record larger than the existing 120 KB per-file boundary is frozen losslessly into bounded part files and a small index; loading verifies part continuity and bytes and compares the complete reconstruction against the same-workspace source run. Protected case results remain excluded. New offline regressions cover source-tail reading, a fourteen-level plain tree, more than one hundred pinned references, full multi-part readback and missing or altered parts. Existing source-run read bounds remain in force; this change does not enlarge them.

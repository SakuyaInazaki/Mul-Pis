# Local mission incumbent and evaluator recovery repair

The host now preflights a trusted evaluator for finite and open-ended missions before assessor work. Missing, unsupported and declined capability produce recoverable host action evidence without an inferred exclusive human gate. Frozen capability filenames include their content identity, preserving the prior gap when the same mission resumes after trusted registration.

An accepted bounded M07 task can select a locally reviewed incumbent when its addressed checks pass, even if another original obligation remains unknown. The selection receipt records each original obligation's evaluated state and gives candidate and observation evidence stable run/task-specific names. Full original fulfillment still requires the original checks and closure boundary. The M04 checkpoint's candidate and observation copies are verified against evaluator bytes during selection and on reopen. Settled prior rejected or failed tasks no longer independently disqualify selection; running or unknown effects still block it.

Offline tests cover missing-evaluator recovery, finite and open-ended capability gaps, two full local task/evaluator/M04/selection rounds with unknown global optimality, an earlier rejected task followed by accepted selection, and equal-length checkpoint-copy tampering. Three older open-ended fixtures now register explicit synthetic or exact-file evaluators before expecting assessor work. Existing unqualified-name selection receipts require an explicit migration before reuse; this batch does not rewrite them. No paid model or user device was used for the source tests. The worktree's temporary `node_modules` link points to a sibling dependency directory and can be removed after testing without removing its target.

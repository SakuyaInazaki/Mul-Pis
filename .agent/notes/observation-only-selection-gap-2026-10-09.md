# Observation-only selection gap

The ordinary local evaluator may pass a check with a trusted host observation while omitting a citation to the candidate bytes. This change retains the accepted M07 task, completed M04 review, evaluator receipt, and checkpoint as unselected partial evidence. It records the exact missing candidate obligation IDs, identities, required read paths, and SHA-256 digests in a bounded selection-proof-gap record. The next assessor must read that frozen record before proposing another task.

Before a later assessment, the host revalidates the evaluator receipt, original candidate and observation bytes, accepted M07 checkpoint, complete M04 read and resolved transaction, and absence of unresolved external operations. A changed or incomplete record holds the workflow. The existing selection path remains strict: a passed check can be selected only when its references include both candidate and host observation evidence.

Synthetic offline tests cover the observation-only continuation into a distinct new task without replay, valid selection, changed receipt bytes, incomplete M04, unresolved M04 transaction, and unknown external operation. No model, network, private evaluator, active mission, or publishing action was used for this change.

The next default assessment now requires every frozen feedback part from its most recent bounded M07 run when that run contains a rejected or failed task. If the trusted evaluator declares a task input contract, the current frozen contract is also required. Earlier bounded feedback remains retrievable on demand. A synthetic default-entry regression confirms exact feedback and contract bytes, full reads before a distinct task, retention of the M04 knowledge snapshot, and provisional dispatch when the feedback read is omitted.

The assessor can now read the latest published knowledge merge through a frozen index and complete pack of that merge's new or revised records. The index binds the published snapshot, merge receipt, current limits, source record hashes and pack-part hashes; it does not treat an unpublished record as adopted. The index is required for awareness. When the latest M07 task was rejected or failed, its next repair assessment must also read every part of the committed pack. A synthetic regression confirms the next task cites that knowledge, and omitting a required pack read keeps dispatch provisional. This does not require the entire historical knowledge database in every assessment.

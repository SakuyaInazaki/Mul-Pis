# Emergency carry fallback

The private campaign finalizer now distinguishes an ordinary carry from an emergency effects-unreviewed carry when ordinary sealing fails. Both paths receive the exact same final request-audit observation. The fallback retains observed fees and an authenticated encrypted checkpoint in the existing confidential carry output, while leaving scientific and restart authority pending. A normal carry is written once with atomic replacement; an output write error does not trigger resealing. Encrypted status and ledger observation report the number of earlier executed runs with unquantified accounting separately from numeric observations. Emergency mode records an incomplete outcome and a nonzero process exit. Tests cover normal-only sealing, fallback with the unchanged accounting snapshot, and refusal when the snapshot mutates or emergency sealing fails. No paid model calls were made; offline tests made no network calls.

# Exact unselected attempt handoff for continuing tasks

This batch fixes a generic input mismatch in the private campaign controller. The original-objective assessor could read the newest unselected attempt, then propose follow-on work based on that version, while the M07 builder received only the selected baseline. The selected candidate and the scientific promotion criteria remain unchanged.

New live assessments receive a host-built, current-run task source index. It identifies the selected baseline and each available host-archived unselected attempt by exact identity and source/plan digest. The small index locates bounded JSONL records. A model-authored grounded next task must select one exact available binding. Choosing an unselected attempt requires current-session reads of that attempt's source, verification, archive, plan, and catalog row, with grounded citations. Unchosen attempts remain retrievable and need no read credit. A missing or changed unselected version returns corrective read-only assessor feedback. Selected baseline corruption or uncertain I/O suspends assessment for infrastructure repair.

Before dispatch, the host copies the selected baseline and chosen attempt inputs from frozen assessor evidence into distinct task inputs, checking each source, verification, archive, and plan digest. Archived unselected material remains development evidence; it cannot independently resolve a selected scientific issue or change the selected tuple. Optional latest-attempt feedback is labeled by exact availability. Essential copy failures produce bounded private diagnostics; a diagnostic storage failure stops the next assessor turn. The private result transporter includes these exact diagnostic names in its encrypted result allowlist.

Historical checkpoint assessment records without a source binding remain readable. Historical unselected research records are still read-only context; this index grants task-input choice only for current-run host-archived attempts. This batch adds no mission time, request, fee, or output admission limit, and does not alter numeric selection thresholds.

Verification: TypeScript typecheck, focused offline Node tests, and the Python private transport tests. Tests exercise zero, one, and many attempts; exact-row read proof; stale and spoofed bindings; selected and unselected input byte checks; diagnostic I/O failure; and historical assessment compatibility. No provider or model calls are used.

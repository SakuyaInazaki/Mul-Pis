A private live campaign exposed two integration defects after the earlier offline checks: relative input declarations were compared against canonical original paths during fork supersession, and the actor's written conclusions preceded the host measurement of the changed source. The independent reviewer correctly rejected unsupported measurement claims; the workflow must repair the ordering rather than relax its acceptance criteria.

This batch repairs frozen-input identity while preserving parent obligations, and introduces an explicit measured-evidence finalization boundary before independent review. Candidate code and host evidence must stay unchanged during finalization. Candidate lesson updates remain pending M04; revising a pending proposal is not an amendment of an adopted knowledge record.

The one-use private rerun trigger remains restricted to the authorized repository, branch, actor, first attempt and exact commit message. Its maximum reservation is reduced to fit the remaining previously authorized budget. Private task material, candidates, measurements and credentials are not included in this change.

The architecture document's Pi source link is corrected to the verified commit already recorded in provenance. Offline check counts and real-run outcomes will be reported only after execution; this note is not a claim of completed knowledge adoption or end-to-end success.

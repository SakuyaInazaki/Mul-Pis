# Assessment continuation and carry evidence

The original-objective assessor now feeds incomplete frozen-evidence reads back to the same read-only session. A provisional malformed or unchanged assessment does not end the mission while required evidence remains unread. Dispatch and scientific outcome decisions still require complete host-verifiable read coverage; actual cancellation, admission failure, prompt failure, or a host-observed read error remain explicit boundaries.

A nonzero assessment-only run with no new M07 goal can be sealed as an abandoned independent-restart claim when its host effect census, assessment receipt, checkpoint transition, selected tuple, research history, and request-to-read-only-session links are all exact. Provider usage and charges remain cumulative observations. Missing or unreceived evidence is refused; historical unknown operations remain quarantined. The earlier zero-work policy fingerprint stays unchanged for existing signed links.

The private driver now places the host request audit in the encrypted outcome before final carry sealing and records a sanitized continuation failure there if sealing fails. This improves offline diagnosis and does not turn a failed seal into a normal carry or authorize replay. The separate result-only screen is structural only; any executed-run gap requires live source, terminal, and artifact proof plus an exact reviewed capability authority.

Synthetic tests cover unread-assessment feedback, a received read-only no-goal seal and reopen, altered receipt rejection, and retained historical accounting. No paid model or external workflow run was made for this code change.

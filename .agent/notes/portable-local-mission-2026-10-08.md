# Portable local original-objective control

This batch adds a local filesystem host for the existing original-objective assessor and M07/M04 workflow. A user-authored objective enters through CLI start, and the Pi extension continues its frozen mission ID. The local host records the contract, ordered checkpoints, process attempts and uncertainty in private files with atomic commit markers. The GitHub Actions admission and encrypted carry reader remain a separate host path.

The local caller freezes selected workspace text inputs, validates full current-session evidence reads, retains prior bounded M07 feedback, and checks the M07/M04 run identity before another assessment. Its optional declared-material bundle preserves original binary bytes and selected text projections in bounded private parts. The model-facing index states unread, nontext, partial-coverage and projection gaps; extraction alone does not prove coverage. The default CLI start uses the exact workspace problem text as an open-ended original goal; structured JSON can name separate obligations. Bounded results stay unselected until an independent host review supplies exact pinned artifacts and original-level checks. A provisional dispatch or uncertain operation remains pending on restart and cannot be replayed from model text. The CLI status and Pi tool return control fields only.

Local execution is opt-in through the workspace configuration. Its Pi bash tool uses a minimal child environment, but it is not an OS sandbox and a same-user shell can access files outside the task directory. The local host is a durability boundary, not protection from a malicious process under the same OS account. Deployments handling adversarial native code need an actual separate OS permission boundary. The default reasoning path does not certify scientific completion.

The original-objective assessor currently reads UTF-8 projections. A selected binary original is preserved as bytes with a visible gap; it is not silently decoded as text. When the default workspace text path encounters an unsupported binary raw input, it refuses to start; a declared selection can identify the relevant original and available projection while leaving unrelated files outside the selected set. The host retains uncertain operation IDs, while clearing them still needs independent local evidence review. Model-free tests exercise the local CLI and production filesystem host through an assessor, bounded M07 task, fresh M04 review, media freeze, and cross-process restart. No live model, API, external action, or native candidate execution was used for this batch.

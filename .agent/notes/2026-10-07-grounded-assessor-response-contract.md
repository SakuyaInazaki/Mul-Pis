# Grounded assessor response contract

The indexed original-objective assessor previously asked for two independently model-authored copies of a next task. One copy used original obligation IDs while the grounded copy also used open issue IDs. Its prompt named an optional deliverable finding without the finding's object schema and did not distinguish top-level filename references from grounded source spans. Validated replies could therefore repeatedly fail at a mirror field without any new scientific disagreement.

The grounded next task now supplies the authoritative obligation IDs, open issue IDs, execution scope, hypothesis and expected evidence. A top-level next task supplies its objective; the host derives its duplicate obligation IDs and scope only after validating the grounded task and the frozen capability registry. Supplied historical mirror fields remain accepted when identical and are rejected when conflicting. Ungrounded historical model responses retain their earlier parser path, and carried authenticated assessments are not reparsed. A task still needs an open explicit requirement or necessary verification issue, complete read proof, and the ordinary host dispatch checks.

Initial and repair prompts use the same response instructions. They distinguish original obligation IDs, open grounded issue IDs, exact frozen filename strings, and line-addressed source spans. They also spell out the complete optional deliverable finding object. A bare readiness boolean remains invalid because the host cannot invent its rationale, citations, or remaining issue list. Fixed validator feedback identifies the conflicting field and expected type without echoing raw private task content. The original objective remains open until independently supported closure conditions are met.

Offline mocked assessor tests exercise rejected replies followed by a grounded correction. They contain synthetic evidence only and make no scientific performance or provider-fee claim.

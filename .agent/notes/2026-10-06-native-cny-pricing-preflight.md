# Reviewed native CNY pricing preflight

DeepSeek's official [Chinese pricing page](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) lists peak DeepSeek-V4.1-Flash rates of 2 CNY per million uncached input tokens, 0.04 CNY per million cached input tokens, and 8 CNY per million output tokens. Its [English pricing page](https://api-docs.deepseek.com/quick_start/pricing/) lists the same SKU at USD 0.30, 0.006, and 1.20 respectively. The shared ratio 20/3 is a published tariff-quote normalization for this SKU, not a foreign-exchange rate or invoice. The [official balance API](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/) returns a billing-currency code and aggregate balances, not per-request charges.

The host now uses a read-only balance-currency probe before constructing a native-CNY campaign budget. Only one unambiguous available CNY currency is accepted; USD, mixed, unavailable, malformed and failed responses stop before a model request. No balance amount, response body or credential is returned, logged or persisted. The live profile is process-branded, carries the model version, official peak CNY and USD quotes, source URLs, pricing effective date, separate account-currency verification time, and source-review time. This reviewed price profile expires at the end of 2026-10-06 UTC, including for a cached profile before any later model request. A later attempt requires a new host review and updated profile.

New native-CNY reservations use the official peak CNY quotes as a floor and compare higher SDK USD estimates through that same-SKU tariff ratio. They do not reuse the legacy factor of 10 or discount for off-peak/cache assumptions when pre-reserving uncached input. The single global 30 CNY ceiling, all earlier charges, and unknown holds stay unchanged. Only price-profile metadata, never account balances, enters the encrypted carry audit. Offline mocked HTTP and carry tests exercise the gates; this batch made no real account or model request.

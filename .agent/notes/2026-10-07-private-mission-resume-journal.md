# Private mission resume journal

Added an offline host reservation journal for fresh mission requests. It stores a private idempotency binding to the terminal source, envelope and pending-action digest, plus the tested source commit and tree, successful CI identity, previous control ref tip, and fixed public control request descriptor. Host-derived actions additionally bind an exact checkpoint digest in the key so they cannot alias historical carried actions. The public descriptor contains no goal, pending action, fee amount or idempotency key.

Records are written with restrictive file and directory permissions, fsynced temporary files, atomic rename and directory fsync. A process lock serializes competing reservations and checks a dead same-host owner before recovery; a lock from a different host stays closed. A ref update is marked attempted durably before any external request; a restarted process treats this and delivery-unknown as unresolved. A new intent cannot replace an unresolved reservation, and later accepted requests must continue the prior acknowledged tip. An exact same-intent retry requires a recorded negative read-only reconciliation and explicit rearm. The journal makes no network or model calls.

Synthetic tests cover restart after reservation and attempt, duplicate and changed bindings, the one-parent case when the control ref already points at the tested source, unknown delivery, positive and negative reconciliation, concurrent reservations and dead-owner lock recovery. No live request or external delivery has been verified by these tests.

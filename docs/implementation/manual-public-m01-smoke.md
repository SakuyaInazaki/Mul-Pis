# Manual public M01 environment check

This is a deliberately small, billable prerequisite check, not a private lab run or a scientific validation. The GitHub Actions workflow is manual-only (`workflow_dispatch`). The temporary guarded push trigger used for the initial connectivity checks has been removed. It uses one fixed, public arithmetic prompt through `ResearchService.runStage(M01)` and a real `PiSessionRunner`, with the `execution` role explicitly set to `deepseek/deepseek-flash:low`. The API key comes only from the `DEEPSEEK_API_KEY` environment variable; the runner does not read a credential file or a global Pi profile.

The pinned Pi SDK's built-in catalog can lag the current DeepSeek name. The entry creates a temporary, secret-free model profile for the [current official `deepseek-flash` model and endpoint](https://api-docs.deepseek.com/quick_start/pricing/). Before any model call, it reads the exact model's output maximum from DeepSeek's authenticated [models endpoint](https://api-docs.deepseek.com/api/list-models/) and checks it against the provider's [chat-completion parameter range](https://api-docs.deepseek.com/api/create-chat-completion/). It then uses that provider maximum in the temporary profile. Pi strict-request enforcement disables retries and compaction, permits no tools, verifies each provider payload, and caps each serialized payload at 12,000 UTF-8 bytes. It does not impose a smaller workflow output limit or an M01 execution deadline. The Actions job has no project-set execution timeout; it retains read-only repository permission and no artifact upload.

The smoke script retains its separate 2.1 CNY total M01 planning ceiling. A per-transport ledger reserves the full live provider output maximum, an accounting margin, and the actual serialized input payload before each HTTP request; complete priced usage releases unused reservations. The configured SDK rates are converted conservatively at 10 CNY/USD. At the documented 393,216-token maximum and current local profile rates, one full-bound request estimates about 4.755 CNY, so a manual run is expected to stop before any paid model request. Restoring a billable smoke check requires an explicit review of its spending allowance, not a shorter output cap. The 2.1 CNY figure and earlier smaller capped-request reserves are historical planning figures, not actual charges or provider invoices. Check the provider's live price page and cumulative spend before any further manual dispatch.

Run offline preflight with `node scripts/manual-env-m01-smoke.ts --check`. Run the actual public check only by manually dispatching the Actions workflow, or locally with a safely configured `DEEPSEEK_API_KEY` environment variable and `node scripts/manual-env-m01-smoke.ts --run`. Do not pass a key on the command line. Neither mode accepts a user-supplied problem path. The run writes its workspace/session artifacts under a temporary directory and deletes it when the process exits normally. Success requires complete, priced assistant usage for every observed provider transport in the genuine Pi SDK sidecar, a final stop response, and a settled campaign ledger. Console output whitelists only check status, stage/model identifiers, the planning ceiling, observed SDK-reported token counts and SDK-estimated cost/completeness. On failure it may report a fixed execution phase, allowlisted harness code, numeric HTTP status and allowlisted stop reason/usage counts from the Pi sidecar. SDK usage is not an independent invoice or proof of model weights. The script never prints the prompt, model response, provider error messages, credentials or temporary paths. GitHub Actions must remain configured without transcript or artifact uploads.

This route cannot validate the private lab: Actions receives only repository content and the API secret, with no supported private input transfer. Do not add lab text, materials, solutions, paths or transcripts to this repository, Actions inputs, logs, caches or artifacts. A later private lab driver needs a separate, reviewed host-local input/output design and a bounded end-to-end research budget; this one-stage M01 check must not be presented as that driver.

# 本地研究工作流面板

本地面板把工作区中已经持久化的运行记录与短时心跳整理为只读图形快照。它用于观察，不会启动、继续、停止、归档或修改研究任务，也不提供命令执行入口。

## 启动

从仓库根目录运行：

```sh
npm run dashboard -- --workspace workspaces/example
```

`--workspace` 显式选择单个研究工作区。省略时，面板只枚举项目根目录 `workspaces/` 的直接子目录；可用 `--root <project>` 改变这个项目根范围。浏览器通过启动日志中的本机地址访问面板。

默认从端口 4317 开始，只绑定 `127.0.0.1`；端口占用时会依次尝试后续端口。可用 `--port <number>` 指定起始端口，或用 `--port 0` 让操作系统选择空闲端口。`npm run dashboard -- --help` 只显示帮助，不启动服务。按 Ctrl-C 会关闭服务并释放端口。

## 状态含义

- **活动**：进程最近写入了仍在新鲜期内的活动心跳。
- **待命**：进程最近写入了仍在新鲜期内的空闲心跳。
- **归档**：持久记录已经结束，包括完成或失败的阶段与已结束会话。
- **未知**：只看到旧的 `running` 记录，或最近心跳已经过期，因而没有足够证据断言进程仍在运行。

前端约每 1.8 秒读取一次快照。这是轮询视图，不是事件流；界面会明确显示连接失败或数据陈旧。心跳只代表近期进程活动，不证明研究判断正确、阶段完成或成员间存在因果调用关系。

界面主体只有一张可平移和缩放的关系图，以 M01–M09 主链和允许的反馈回环呈现工作流结构。结构连线表示规则允许的路径，不表示每条路径已经实际执行。点击阶段会进入该阶段的聚焦画布，在中心节点周围同时展开全部已有运行和关联 agent；再次点击中心节点返回主链。展开的节点可以拖动，点击则查看安全元数据详情。双击图中留白可重新适配视野。

## 读取边界

服务只接受 GET 请求。`/api/workspaces` 只返回启动时登记的工作区 ID、显示标签和初始化状态；`/api/state?workspace=<id>` 只返回面板所需的安全元数据。客户端不能提交文件路径，也不能借接口读取任意文件。

响应不包含绝对机器路径、原始会话文本、prompt、密钥或研究产物内容。静态文件限制在 `src/dashboard/public/` 内，API 响应设为 `no-store` 并有固定大小上限。Host 与 Origin 必须指向当前本机服务地址；这项限制用于阻止外部网页读取本地研究状态，不等同于面向公网的身份认证体系。

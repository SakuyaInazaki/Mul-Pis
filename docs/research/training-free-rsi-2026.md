# 固定模型权重的工作流递归改进

研究整理日期：2026-10-14。本项目研究 training-free RSI：固定 API 模型权重，通过可继承的执行源码、改进源码和科学知识改变后续研究行为。本文为文献依据与实验设计，不是已获得 RSI 收益的声明。

## 阅读范围与结论

已完成107篇唯一论文的可获取PDF全文及自带附录，共3512页；104篇连同可确认的引用补充材料完整，另3篇缺失外部补充。版本不重复计数。逐篇阅读记录覆盖方法、实验来源、数值与比较条件、适用范围、反例和后续可证伪实验。摘要只用于筛选。公开书目及实际阅读版本见[论文目录](training-free-rsi-bibliography.md)；原论文版权仍属各自权利人，仓库不附下载的PDF。全文完成不代表代码复现。

现有成果支持固定权重系统通过提示、记忆、工具和harness修改改变任务表现，但需要区分六个观测：产生补丁、实际加载、行为改变、执行策略H受益、改进策略I受益、多代收益增长。知识K被加载、被忠实使用与产生因果收益也应分别检验。圆桌讨论对这些问题的重视可以指导研究；RSI的定义仍有分歧，不能把一种定义表述为全部研究者的共识。

## 复用现有工作流

M01–M09继续承担原有研究阶段，C/K/E/J/Q/D/X继续是唯一知识库。M04保持科学判断与知识采用路径。原始记录和版本保留，当前可用视图、适用条件、必要引用及撤回状态控制未来使用。方法或模型停止运行不会清除知识库。

沿用现有GenerationStore记录H/I/K、父子关系、活动指针及回退；沿用完整Git提交和只读源码快照记录真正运行的实现。首轮H只开放证据交接模块，I开放研究动作选择程序。评价、工具权限、知识合入、原任务义务、用量结算与活动指针留在固定控制部分。这个范围用于明确比较对象；同用户文件系统上的源码只读权限不构成OS安全沙箱。

改进器能选择读取开发证据、请求模型分析、组织候选、选择开发评测与决定停止。模型通过受限文件工具修改独立候选副本，形成自己的可证伪假设和真实提交。工程检查、完整补丁、候选会话和费用均保存。宿主修复与模型生成候选分别记录，不能把宿主写好的修复算成模型发现。

真实结果评价在固定父进程中进行。执行臂收到当前任务的材料和原始义务，隐藏答案留在父进程。父进程核对原证据、M07产物、M04实际阅读、知识事务和知识前后状态。机械完整性、科学事实正确性、合理保留未知和知识增量分别报告；不再仅用报告关键词作为源码采用依据。

开发选择先冻结，之后才打开确认案例；通过预声明规则后只改变后续新会话的源码选择。已运行目标保持原版本。准入和回退均检查当前知识限制、必要引用和预期活动指针。H与I的源码绑定分别保存，替换I不会顺带替换H。

## 真实实验顺序

1. 同源码A/A：真实模型、独立进程和工作区，交替执行顺序，检查语义评价器、M04回流和用量差异。它验证测量链，不产生改进结论。
2. H对照：固定I/K，让模型从实际开发经历生成H源码候选；在新任务材料上比较质量与全部可观察成本。
3. K对照：固定H/I，比较合法经验的有无、适用条件变化和撤回后的行为；保留原库与历史。
4. I对照：旧I与新I从共同H/K和开发机会出发，各自产生H后代，再对后代进行独立确认。搜索成本与最终部署成本分账。
5. 递归继承：新I实际承担下一次搜索，至少观察两次代际转换的装载、行为、后代与评价链。单次成功不宣称持续加速。
6. 后续真实任务：使用采用的源码继续实际任务链，检验局部证据交接效果能否迁移到完整研究工作。任务基础设施由工作流处理，宿主维护干预另记。

第一批机制实验使用真实论文的方法、结果、反例和适用范围，要求正确核对主张并交给M04处置。开发、A/A和确认材料按不同论文来源分开；私有答案不进入改进器。它具有真实科学证据处理内容，但不能替代后续实际算子任务的端到端实验。

确认前固定主要终点、独立统计单位、样本和重复数、成本口径、失败分母及选择规则。发生失败的调用不删掉，未知用量不写成零；SDK估价与真实账单分开。质量与费用优先分别报告，不使用没有研究单位依据的任意加权分，也不以未检出差异宣称质量等效。没有证据支持的候选保留研究记录，活动版本不因版本号递增而改变。

## 实施记录

本轮通用工程增量围绕源码候选、实际I程序加载、父进程结果检查及源码采用展开。离线测试检验控制路径；真实API实验、H收益、I收益和多代结论以独立实验记录为准。完整接口与版本适用范围在[实现说明](../implementation/rsi.md)持续更新，历史v1文字检查和提示策略路径保留其原本含义。

## 首批真实运行观察（截至 2026-10-14）

这批实验检验的是固定模型权重下、M07 证据交接与 M04 知识处置的局部机制，材料来自真实论文；尚不能推出完整科研任务收益或递归自我改进。先用相同 H/I 源码、相同初始知识做 A/A 校准：两种材料各重复两次，共四对、八个独立执行臂，均完成 M07→M04 并得到可检查的结果。同源码臂仍出现不同的科学处理结果，因此不能把单次波动当作改进。最终 v5 校准的八臂均可检查；v6 对同一批冻结执行与已核评审做离线重评，未产生新执行或模型调用，质量结论相对 v5 未变。

H 开发实验在两种已见材料上各重复两次。按冻结的科学核心义务，基线四臂有 3 臂全通过，候选四臂有 2 臂全通过；预先声明的开发规则记录两项退步、一项改善，拒绝候选，搜索没有赢家，新 H 未激活。两次初始观察与后续搜索合计的可观测 SDK 估价为 **0.734005668 美元**，其中搜索费用已包含候选构建、成对执行和独立评审，不重复计费。这是开发集结果，不是保护集准入。

K 对照固定 H/I，在四个新知识臂的任务材料中均实际投递同一新增知识引用；三份冻结 M07 报告引用它，四份 M04 处理正文提及它。投递和引用不等于忠实使用，也不证明因果收益。原运行记录的核心义务全通过数为旧知识 3/4、新知识 1/4；v6 用原执行回执及已核独立评审离线重评为 3/4 与 2/4，仍有一臂科学检查未知。另一项 v7 **事后表示复核草案**将该臂的百分比单位表示重新解析为通过，得到 3/4 与 3/4；它不是运行时评价版本、新执行或新的采用决定。八臂执行和独立评审用量均已结算，产生新增知识的原 M04 调用也只计一次：旧知识四臂 0.235962660 美元，新知识四臂 0.335737992 美元，知识产生 0.039524616 美元，共 **0.611225268 美元**的可观测 SDK 估价。原 K 汇总仍保留 `complete:false`；逐臂和该 M04 调用的用量记录均完整，费用完整与科学检查完整是两回事。

I 实验的模型候选 I 源码通过工程检查，并实际装入独立改进器子进程。旧 I 与新 I 均完成内层 H 搜索并返回 no-winner；候选 I 调整的决策分支在本轮未触发，因此未观察到可归因于该改动的策略行为差异。双方无赢家后，以共同原 H 执行后代比较；这部分是同 H 的会话波动，不能归为 I 收益。最终八臂中六臂返回、两臂在宿主休眠及 API 连接中断期间未完成；部分已返回臂另有科学检查未知。比较结果为 unknown，外层因用量未完整结算记为 incomplete，实验停止，保护集未打开、没有采用、未进入第二代。

I 的两次初始观察为 0.182255904 美元，外层搜索已观察费用为 1.732447632 美元，合计 **1.914703536 美元**；外层已包含内层搜索、候选构建、执行和评审，不能再叠加。仍有 8 个未知用量事件，该金额不是完整费用，未知部分没有记为零。终局材料随后交真实 M04 独立处理，完成知识合入及知识 epoch 前移，原 H/I 保持原值；这次 M04 的可观测 SDK 估价另计 **0.045299100 美元**。新增记录的当前可用性继续受候选状态、依赖和复核限制约束，合入不等于科学采用。

随后发现并修复通用 M04 知识修订说明的缺口：局部修订省略状态字段会继承旧值，普通反馈也需要看到现有 executor/improver 经验格式。新真实 M04 会话已纠正与正文矛盾的旧依据状态，并完成第二次知识 epoch 前移；H/I 保持原值，候选状态和复核限制保留，当前正式经验选择仍为空。这次复核另计 **0.052656900 美元**，可观察用量完整。该修复验证了知识状态更新链，不能据此认定新增经验已经适用于下一轮。

这些金额覆盖对应运行中可观察的 provider/SDK 估价，不包含人工、外部资源或实际账单差额。每个实验总额按不重叠阶段汇总；已包含在父级搜索中的子搜索明细仅用于核对。

第二次 I 开发实验使用两份新 H 观察及保留的前轮开发反馈。模型产生的新 I 通过工程检查并实际装入独立进程；其新增的 unknown 停止理由分支在终局触发。同一实际状态的离线核对中，旧 I 和新 I 都停止且不选择候选，只有理由文字不同，不能把这项变化记成搜索或科学收益。旧 I 生成的 H 因最终假说交接格式被拒；新 I 生成的 H 通过工程检查并完成八个新执行臂，其反馈修改确实进入 M04 消息。这一侧有一份 M07 报告包含无效 JSON，导致必要科学检查无法确定，原开发结论为 unknown。两侧都保留共同 H 后，本轮预先声明的未定结果门保留 unknown，未追加同 H 会话比较；没有进入保护比较、采用或第二代。

第二次 I 实验共记录 **110 个用量事件**，全部已结算，未知用量事件为零；两份观察为 0.164370084 美元，外层 I 搜索为 1.110913560 美元，合计 **1.275283644 美元**的 SDK 估价。外层费用已包含 I/H 构建、内层搜索、执行及评审，不再叠加。宿主随后修复了动作开始时误写 completed、构建器格式契约与解析不一致的问题，并把协议测试夹具从可演化 I 策略中分离；这些是通用工作流修复，不计入模型候选的收益。

第二次 I 实验的终局回流首次收到正常 stop 但无可见正文的回答，旧 M04 将其误作无提案完成。通用修复现将空答复送入原判断修复路径；离线用例验证了空答复纠正和正常无提案结果。随后新的真实 M04 得到完整报告，在同一会话纠正无效提案 JSON 后，新增一条 candidate 实验记录、更新一个开放问题，并使知识 epoch 从 G003 前移至 G004；H/I 及五条既有限制保持原值。这次真实重跑命中提案格式修复，空答复分支的验证来自离线回归。原空答复调用费用为 0.156767400 美元，新回流为 0.353768400 美元（已含实际 200k compact 的 0.150462600 美元），连同第二次 I 实验合计 1.785819444 美元，全部可观察用量已结算。

后续实验设计调整为：在同一份真实 M07 checkpoint 上分别运行 H 交接和独立 M04，评价实际处理报告与知识入库结果。当前 H 可编辑的反馈函数发生在 M07 报告冻结之后，M07 报告本身的质量作为共同输入资格；独立评审须实际接收 M04 的 processing.md，包括无提案理由。新的维护源码、评价协议和 A/A 校准将单独登记，历史完整工作流对照保留原结果。该共享输入协议目前处于实现与离线接线阶段。

# 十六、整体复查：采用、替代、接口与待实施边界

## 1. 本次对齐后的重要接口

独立初始认识与后续知识复用不冲突：第一次面对新问题不加载先前解题分析；当前项目后续执行按目标读取知识包。不能将“必须读知识库”设成压过所有阶段边界的默认动作。

两次判据调用不形成两套标准：首次建立 K，读到外部内容后按同一条目增量修订。M05 下载不能关闭 Q，M06 读到内容也须经过论证与处理才改正式使用状态。

材料首轮隔离与项目综合不冲突：搜集者需要知道问题；首轮读者忠实读材料、不接收预期结论；主 Agent 后续负责对照项目。给读者的来源元信息不能夹带研究倾向。

notes 与图不重复分工：行为日志涵盖全项目，科学论证与采用决定在 J/D 等记录中，双方相互引用。导出初始回答是复制便利，不因后来使用图而追溯改变原意。

候选、工作假设和未决可保存并探索，知识入库不等于正确性认证。历史采用决定、当前可用性和资料取得情况分开。关闭质疑、同意评审、不再使用均不自动判科学真假。

上游修正与下游限制同时生效。已知停用优先于旧快照，完整修订失败和回退不得让已知错误无提示复活。未知科学问题限制状态升级，不禁止其他正常探索。

重要版本冻结贯穿对象含义、数据、代码、配置、判据、实际证据与视图；审查冻结不冻结所有并行探索；交付副本与原工作区分别核对，不将更改后的交付自动继承旧审查。

## 2. 明确不恢复的旧建议

| 旧建议或误解 | 本版最终处理 |
|---|---|
| 初始认识与候选判据合并成一个巨型 prompt | 保留两次交互 |
| 初始认识前先查外部定义或加载旧项目知识 | 撤回，先独立认识 |
| 原样导出主要为了审计冻结 | 撤回该意图解释，导出用于复制转交 |
| 在初始提示中枚举无关任务名称 | 不再加入 |
| 用户亲自生成专业压力测试题 | 改为网页版 AI 出题、用户转交 |
| 说“需要条件/计算才判断”就判不懂，强迫方向反转 | 允许有理由的不确定和条件内不反转 |
| 四类攻击只检查执行 Agent，评审永远正确 | 出题、预设答案和评价本身也受检验 |
| 每问由用户单独下令独立检查和失败诊断 | 保留目标委托，必要检查与一般调试内部编排 |
| notes 是本轮评审意见分类表 | 保持全项目行为记录，具体论证与处理在知识记录 |
| 只有两份长文独立手填知识和纠错 | 有版本记录及图关系为主体，长文是阅读视图 |
| 每条话都构图、支持数越多越可信 | 不采纳；关键内容入图，同源证据不重复计数 |
| 合入知识库/关闭 Q/批准使用就等于证明正确 | 明确分开记录、依据与当前可用性 |
| 上游变更先发布，之后再标下游影响 | 先分析并随变更一起发布必要限制 |
| 恢复上一完整版本就自动恢复所有旧条目可用 | 已知停用和权限限制不得被回滚取消 |
| 并发只看是否修改同一文件 | 串行合入并复查读依赖、关系新增与决定条件 |
| 固定跳过摘要引言、只读公式附近 | 阅读必要上下文，不按章节名统一删除 |
| 资料都做完整卡片，未定用途就将全部公式当拟用 | 渐进提炼，实际依赖与疑点优先 |
| AGENT/LIT 标签或规定全部只许人工核验 | 核对事实、主体与范围如实记录，不伪造人工验证 |
| 文献真冲突直接取 min/max 当合法区间 | 对齐条件并保留争议，不自动平均或建立硬区间 |
| 材料数量、搜索重复出现等于检索完整 | 按需求覆盖、实际范围和缺口结束 |
| 所有子 Agent 都永远互不可见 | 按任务隔离；综合者需要各方证据 |
| 审查包一律删除 IO、数据清洗和绘图程序 | 按是否影响结论判断范围 |
| 新目标基准覆盖原问题，用户批准等于科学等价 | 原问题、授权变更与证据支持分别保留 |
| 每次按相同固定 AI 数、统一工具和语言执行 | 依据任务与项目约定，不复制竞赛配置 |
| 收尾必须写论文、压包或不断生成队友包 | 根据接收者与用途，只交必要材料并停止 |
| 正式工作后继续进入 RSI/方向层作为必经环节 | 本版不纳入；当前执行主线在收口处结束 |

## 3. 仍属于实现/试用问题，不伪装成已完成

图数据库选型、自动索引器、校验器、持久化/合入程序、上下文读取隔离、访问控制与具体工具启动配置，需要在部署实现时确定并测试。文件式组织是第一版形态，不意味着仅复制本手册便具有原子事务、可信隔离或自动科学判断。

实际项目参数、资源额度、运行工具、可分享范围和领域专用验证方法由具体问题及授权确定。它们是实例化输入，不是遗漏的额外通用阶段。实际新增需求超出一项目一权威库等 v1 范围时需明确扩展，不偷偷宣称既有设计已经支持。

本轮没有重新调查此前新闻、论坛采用数字或系统成绩；这些不构成本版规则有效性的证据，也不纳入主流程。原始附件内的 Agent 回报只用于定位历史操作，不能冒充当前独立核验的科学事实。

## 4. 来源与历史的对应

本版规范的主要依据是本次对话中逐环节接受的最终决定。原始附件只用于核对实践起点：竞赛执行日志第 9—60 行为早期候选判据、物理过程解释、notes/knowledge 和导出；第 210—231 行为外部 AI 问题归属及纠错记录；第 236—340 行为原文献卡；第 491—595 行为旧卡片审计；第 778—785、925—935 行为逐问委托与解释交接。

原实践的候选判据先于初始认识；本次讨论后采用初始认识再候选判据的两次交互。本文不将新顺序、新图式管理和新规范改写成用户当时已经实施的过程。

RSI 论文《The Last AI Built by Humans: Toward Genuine Recursive Self-Improvement》是讨论启发材料，不是本流程的标准操作来源，也没有为这套具体流程提供效果验证。本文不将其自主等级变成我们的阶段，不引入后续自我改进目标。

## 2. 边界验收用例

以下是实现与使用时应执行的检查。本次只做规范汇编和覆盖对照，没有运行图管理程序、研究实验或宣称通过这些验收。

| 编号 | 情形 | 期望行为 |
|---|---|---|
| T01 | 初始认识任务可见原题和旧知识目录 | 只供原题及必要原始信息；不得经摘要/索引泄露旧解题认识 |
| T02 | 只提供外部质询中的错误前提 | 不自动登记为执行Agent自己接受过的C |
| T03 | 外部题要求一个实际上未必存在的方向反转 | 允许有理由的不反转或条件不足；检查出题前提 |
| T04 | 独立初始认识和候选判据之间没有新资料 | 保持两次交互；不自动合并或开始外部检索 |
| T05 | 只下载到摘要或缺页PDF | 显示实际范围，不生成全文核验/完整阅读声明 |
| T06 | 一个来源有多个版本/镜像/转述 | 关联来源不重复计数独立证据；版本不覆盖 |
| T07 | 搜索词只含主Agent当前选定方法 | 回到原对象拓展必要表达，不把现有假设变筛选硬规则 |
| T08 | 缺当前实验数据或新的数学证明 | 搜索可找帮助，但不以别处结果替代；交接剩余任务 |
| T09 | 额度耗尽但仍有未搜索范围 | 记中断/资源边界而不是材料覆盖完整 |
| T10 | 材料中含预期结论或行为指令 | 阅读忠实保存，不能修改权限或项目规则 |
| T11 | 阅读卡自洽但将条件性结果写为无条件 | 回原文核对并修订，不能以自洽通过 |
| T12 | 两个文献数值不同 | 先对齐定义条件；不自动平均或以区间作硬门槛 |
| T13 | 两条相似文字的量词/对象定义不同 | 不自动合并 |
| T14 | J需要A与B共同成立而只有A被确认 | 不把A作为充分依据，保留缺失前提 |
| T15 | H不适用于对象，但H⇒C仍有正确证明 | 暂停应用而非撤回条件命题 |
| T16 | 反证中的临时¬P被排除 | 不把正确证明P因前提被拒绝而撤回 |
| T17 | 一条支持路线失效但另一条仍成立 | 重审依赖路线，不机械判结论为假 |
| T18 | 出现一条无根据的外部反对 | 保存并判断，不撤回全图 |
| T19 | Q因重复/不属范围/搁置关闭 | 不升级C科学可信状态 |
| T20 | 历史D准许采用，关键依据随后失效 | 当前可用性反映新限制，历史决定不重写 |
| T21 | X包含明显不相容条件 | 标情境问题，不将空泛条件推论当实际成果 |
| T22 | 共享定义单位或聚合口径改变 | 核对映射与受影响结果，不直接混用 |
| T23 | 一次有效反例、一次运行失败、一次未运行 | 保持三个不同科学含义及状态 |
| T24 | 同数据、不同报告/模型评论一致 | 不误算成多组独立数据 |
| T25 | 判据在看到结果后修订 | 保留原始结果旧评价和修改依据，重评不混分 |
| T26 | 上游确认失效、下游复算尚未完成 | 限制随上游变更生效，不存在无提示可用窗口 |
| T27 | 紧急停用登记后完整发布失败 | 停用继续有效，旧快照不能恢复默认使用 |
| T28 | 两Agent改不同对象但关系上互相冲突 | 串行合入重查当前依赖与相关新增对象 |
| T29 | C文本未变但新增重要Q | 依赖C的待合入采用决定重新检查 |
| T30 | 同一完成通知重复或发送超时 | 用操作/尝试身份核对，不新增虚构执行次数 |
| T31 | 某次执行是否成功无法确认 | 保留结果未知，不盲目重复有外部后果操作 |
| T32 | 发布在任一步中断 | 只供上一完整状态或明确拒绝不完整状态；保留已生效限制 |
| T33 | 图版本固定但E所指latest被覆盖 | 发现内容不一致，不能冒充旧证据 |
| T34 | 旧分支成果提交时当前主线已变 | 检查实际依赖影响；无影响可合入，有影响重审 |
| T35 | 当前回退至旧内容 | 不撤销现已知限制和真实外部后果 |
| T36 | 来源暂无法访问、损坏或作者撤回 | 分别处理可得性、完整性和内容可靠性 |
| T37 | 规范升级含未知类型/字段 | 显式迁移或拒绝解释，不静默删除信息 |
| T38 | 局部知识包容不下结论和条件 | 缩小/分批/标未完整，不只给裸结论 |
| T39 | 缓存与当前库版本不一致 | 说明版本并按用途更新，不冒充当前 |
| T40 | Agent已经读过被撤回旧认识 | 关键动作和验收前重查，不假定自动遗忘 |
| T41 | 图中没记录某内容或权限不允许看 | 不把未记录/未可见推成不存在 |
| T42 | 影响图过大或存在隐含依赖 | 报告已检查范围并补必要直接审查，不伪报无影响 |
| T43 | 索引损坏或丢失 | 从权威记录重建并核对；失败明确降级 |
| T44 | 需要删除敏感内容或撤销访问 | 处理正文缓存索引视图与可分享限制，注明不能完整重放 |
| T45 | 用户要所有位置达标，代码判断平均达标 | 认定输出口径不等价，不能以程序运行正常通过目标核验 |
| T46 | 只完成特例或获得反例 | 按与原目标的关系报告阶段成果，不冒充全面完成 |
| T47 | 图上支持完整但实际代码/推导使用未记录假设 | 从原始产物查漏并补相应依赖和论证 |
| T48 | 测试存在但被跳过仍显示成功 | 记录未执行并核查检查器，不把输出标志当证据 |
| T49 | 交付删除或搬迁后原本运行通过 | 在实际交付副本重查路径依赖和必要运行 |
| T50 | 只重画图或重跑分析 | 不称完整复算或重新实施实验 |
| T51 | 交付准备好但没有发送授权 | 不公开、投稿或自动发送 |
| T52 | 本轮结束时仍有实际运行任务 | 如实安全处理或报告继续状态，不能伪称已停 |

验收既检查错误是否被阻止，也检查正常探索是否被过度阻断。实现后还应覆盖操作重排、事件重复、发布中断、旧版本交错和访问变化。已知测试通过只说明其范围，不证明所有科学判断都正确。

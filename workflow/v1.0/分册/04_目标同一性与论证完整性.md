# 十一、贯穿规范：目标同一性与论证完整性

## 1. 保持的是问题，不是最初方案或预期答案

目标同一性指原对象、问题含义、量词、范围、输出口径和成功要求不能未经说明改变。模型、思路、方法和预期答案可以被证据推翻。研究“机制 A 是否解释 B”不得改成“必须证明 A 解释 B”。

执行层中推导、反例搜索、路线比较属于怎样解决当前问题；不等于重开方向层。原构造目标最后得到不可能性结果，可以是重要成果，但要说明取得的是反对构造可能性的结果，不冒充完成构造。

## 2. 目标基准

由原始问题、原始材料中的明确要求及用户真实澄清，整理出可回查的目标基准。结构化解释与用户原文分开；新增假设、方法限制、精度、阈值或时域不能冒称题目要求。

提取研究对象、所问问题类型、量词/范围、目标量定义及统计/空间/时间口径、明确约束、足以回应问题的成果形式。实质歧义才向用户明确提出，不让用户预先给出正确解法。

不向独立初始认识提前注入“正确答案”。目标整理可从初始解释中产生，在首次实质执行前核对。事后补建必须标明事后整理，不能伪造当初已经确认。

目标基准可以通过原始输入、C 定义/主张、X 情境和 D 授权关系表达；不另造一套独立事实库或额外必经交互。

## 3. 转换逐项说明

原问题 → 形式化/模型 → 子任务 → 实际推导/计算/实验 → 输出处理 → 最终结论，每个关键转换说明保持了什么、新增什么、怎样回应原目标。

| 转换 | 必须说明 |
|---|---|
| 等价改写 | 定义映射或等价理由；文字相似不够 |
| 子问题、引理、特例 | 其在原目标中的作用；局部完成不冒充全部完成 |
| 近似、代理问题 | 适用条件、误差或连接原问题的理由 |
| 实质变更 | 变化、影响及明确授权；保留原目标未完成部分 |

证明 L 能推出 T 才能说明以 L 完成目标 T；只有 T⇒L 不足够。平均值、所有位置、最大值、首次入带、此后保持在带内不能混用。代码和数据处理的实际操作也要对照，而非只比标题。

主要目标启动、核心定义/假设变化、子任务合并、对外交付时做对照，不要求每次工具调用重读原题。最终从目标到成果找漏答，从成果到目标找未经授权的扩大。历史不足时只说明当前对齐程度，不宣称全程没有偏移。

## 4. 论证链完整的含义

对每项主要结论，核对起点、关键推理、条件相容、实际执行证据和终点表述。用已有 C/E/J/K/Q/D/X 关系组织，不以图连通代替论证有效。

起点可止于明确题设、定义、准确引用且前提已核对的已有结果、真实原始证据、明确假设或形式系统基础；不要求无限重证全部基础，但假设身份不能被隐藏。

演绎研究核查定义、量词、假设、推理规则、临时假设作用域、分情况覆盖及最终命题。经验研究还要检查测量定义、样本或数据形成、选择与处理、分析方法、误差/不确定性和替代解释。数值复算只支持相应实现事实，形式检查只相对所写规格成立，不能替代规格是否忠实或模型适合真实对象的判断。

重点补齐影响结论的步骤，不是把每步简单运算无限展开。优先检查共同前提、没有替代支撑的关键 J 与核心主张，同时记录其他主要结论覆盖范围。沿图回溯之外，直接阅读实际产物找图里漏记的假设和依赖。

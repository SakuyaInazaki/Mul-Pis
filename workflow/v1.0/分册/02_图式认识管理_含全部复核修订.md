# 七、贯穿规范：图式认识管理 v1.0（含全部复核修订）

## 1. 定稿范围与基本原则

采用文字内容加结构化关系，以可单独引用、质询、修订或影响后续研究的关键内容为单位。不是每句聊天一个节点，也不是只有文件名和“相关”箭头的总图。自然语言、公式、原始数据和实际程序继续是内容主体；图组织其依据、条件、质疑和变更关系。

第一版运行范围：一个项目、一份权威知识库、多个并行研究任务、一个受控制的串行合入入口。不声称已支持多设备无协调写入，不自动建立跨项目普遍真理库，不以一万个 Agent 或任何未披露的外部系统实现作为本方案依据。

外部来源由 `references/` 管，项目行为由 `notes/` 管，知识记录由 `knowledge/` 管，索引与阅读视图从这些内容生成。图索引不是另一套手填事实库，反向关系不重复维护。

图能自动检查引用、版本、结构、权限和明确停用等已实现规则；不能自动裁定所有科学真假。自然语言推导、条件充分性、情境等价性和证据适用性，仍需要相应的实际判断方法。没有方法就保存论证与未决状态，不让通用遍历冒充科学证明，也不无限追问“谁验证验证者”。

## 2. 七类知识对象

| 类型 | 内容 | 最低应保留的信息 |
|---|---|---|
| C 认识条目 | 定义、假设、机制解释、命题或经验结论 | 具体表述、必要定义、范围、来源身份、不确定性 |
| K 候选判据 | 用来检查认识或结果的规则 | 检查对象、前提、办法、性质、结果含义及不能证明什么 |
| E 依据项 | 原文内容、原始数据、实际计算输出、证明检查记录等 | 来源与版本、精确位置、实际内容、取得/核对范围及同源关系 |
| J 论证记录 | 怎样由前提与依据支持、反驳或限定目标 | 输入及作用、联合关系、目标、论证正文、条件、实际检查 |
| Q 质疑与未决 | 外部批评、条件缺失、证据冲突或无法判断的问题 | 原意见位置、针对对象及版本、理由、影响、处理状态 |
| D 处理与修订决定 | 对认识和判据的采用、限定、暂停、撤回、替换等处理 | 处理对象与情境、理由及对应论证/依据、授权、替代关系、影响 |
| X 研究情境 | 模型或研究分支共享的定义、条件和比较口径 | 对象、范围、定义、假设、条件关系与尚未确认的映射 |

N 来自行为记录，S 来自外部资料，不在知识库复制完整正文。初始认识可以只有 Agent 自身推理的来源身份，不为凑 E 强迫提前引入外部资料。

J 回答“为什么受到支持或反对”；D 回答“在当前用途下如何使用”。有人采纳不等于证明成立；暂不采用不等于命题为假。论文声称 P 与 P 对本项目成立，需要分开，并通过适用性论证联系。

## 3. 关系的含义与唯一写入位置

| 关系 | 由哪里定义 |
|---|---|
| C/E 作为 J 的前提或依据 | J 的输入及作用字段 |
| J 支持、反驳或限定 C/K | J 的目标、结论与条件 |
| Q 质疑 C/K/E/J | Q 的目标字段 |
| K 检查某个主张或实际结果 | K 的检查对象 |
| D 处理 Q 并改变使用决定 | D 的处理内容 |
| 新旧版本替换或拆分 | D 的替换/拆分关系 |
| 内容适用于某情境 | 条目/论证的范围与 X 映射 |
| N 使用或产生具体内容 | 实际行为记录 |
| E 定位 S 或实际产物 | E 的来源与位置 |

“读过 S 并写出 C”只能先说明行为关联，不能自动建立 S 支持 C。“相似”“引用”“共同前提”“严格推导”“经验支持”“反例”不能都压成同一种箭头。尚未核对的关系可作为候选，不自动引起大范围撤回。

## 4. 论证结构：共同前提、替代路线、局部假设

一个论证需要 A 与 B 同时成立，要写成 A∧B 经 J1 支持 C。另一条 D 经 J2 支持 C 是替代论证，不与第一条混为任选前提。J 自身可能有错误，输入成立不保证 J 有效。

J 的输入作用至少区分：实际应用条件；用于证明条件命题的局部假设；反证/分情况中的临时假设及其解除位置；定义、原始数据和已采用结论。不能把所有输入按同一种事实依赖传播。

特别区分“已证明 H⇒C”与“当前对象满足 H，因此当前 C 成立”。若当前对象不满足 H，当前应用可能失效，条件定理本身不因此撤回。反证中假设 ¬P 后推出矛盾，该临时假设不是项目采用的事实，不得因拒绝 ¬P 而撤回正确证明 P。

关系图可以有环，但循环引用不增加独立证明。归纳证明、联合模型或耦合方程应保留真实规则和论证作用域，不能机械因有环判错，也不能因连通判真。

## 5. 三种状态分开

第一是依据状况：问题给定、工作假设、原文陈述、本轮推导、数值检查、独立复算、形式检查等具体事实和未覆盖部分，不设置单一升序可信等级。

第二是历史使用决定：候选、工作假设、当前采用、暂停、已撤回/已替换。决定绑定情境、用途和版本，不等于永久正确。

第三是当前可用性：根据使用决定、情境匹配、依据状况、版本变化、阻断问题和权限，得出本任务可按条件使用、仅探索性使用、需复核或不允许使用。它是派生判断，不与历史 D 混为同一标签。

另外显示开放质疑、依据变化、材料不可取得、论证失效等具体标记。一般未证实质疑不自动使全项目停摆；有充分依据的停用和明确权限限制则不能被一般采用决定覆盖。

Q 可以因已回答、质疑不成立、重复、不属范围或搁置而关闭。关闭 Q 不自动证明目标认识正确。未记录、缺少支持、受到质疑、暂不采用、被反例否定，各有不同含义。

## 6. 身份、版本与情境

关键引用固定到具体版本，如 C014@1；知识库发布状态可记 G018；情境可记 X003。项目间必须有身份边界，不能用同一 C 编号直接混接。序号仅是身份，不是权威排名。

实质修订产生新版本；拆成多条或改变对象含义时建立新条目及拆分/替换决定。重命名不改历史含义。语义相似只作为候选对应，不自动去重；同名、相同输出数值不保证同一对象或同一次实验。

旧 J 引用了 C014@1，出现 C014@2 后不能自动替换其前提。替换表示项目采用变化，不表示逻辑等价。不同情境下可并存不同方案或状态，不按“较新”覆盖其他分支。

X 要保留定义、量词、单位/坐标/统计口径及约束。明确矛盾条件应显露；未发现矛盾不等于已证明相容。情境映射只有已建立、部分匹配、不匹配或未定等有理由判断；转换未确认时不合并结果、不直接比较。不能把空前提对象或不相容情境中的空泛推论当成现实成果。

## 7. 依据与事实的细分

E 中区分实际取得范围、文件完整性、可访问性、内容可靠性和核查情况。网站暂不可访问不等于结论为假；文件变化不等于作者撤回；撤回须检查原因与所用内容范围。

原始运行事实、从结果得出的解释以及接受该解释的决定分别保存。评价规则变化不删除历史输出，只重新评价其意义。

有限例子不能证明一般命题；运行失败不是有效反例；没发现效应不证明效应不存在；仿真贴合不自动唯一识别机制。随机性、重复种子、同源数据、分析选择和不确定性按实际对结论的影响记录，不把多个 AI 或转述重复算成独立证据。独立性可以按数据、方法、实现、审阅输入区分，不明则写未知。

重要事实记录事件发生、材料发布、取得、登记和决定生效的时间含义；因果关系不能仅凭不同机器时间戳猜测。原始内容无法恢复时，保留阅读与引用的可追溯限制，不凭摘要重造原文件。

## 8. 影响分析的规则

上游改变时，沿已建立关系找到直接依赖的 J、相应 C/K 和实际采用过它们的产物。传播“需检查”而非机械传播“为假”。一条 J 失效但另有支持，需要检查剩余依据；条件范围变化检查当前情境；纯措辞等价修订不必全量重算；一般主题相关不作为强依赖。

审查既沿图追踪，也回原始产物寻找漏记关系。输出影响范围时明确覆盖依据；未能完成全图检查，不能报告“无其他影响”。核心共享定义和广泛假设变化，还要检查隐含依赖。

## 9. 最终更新协议与停用优先规则

接收与定位 → 候选修改 → 结构及语义检查 → 已知影响分析 → 在最新状态上复查依赖和授权 → 整体发布 → 后续复核及交接。

发布必须包含上游变更以及已知下游必要的待复核/暂停标记。昂贵复算可在后面做，但不能先发布失效依据，再让下游无提示地继续显示可用。

对于有充分依据或明确授权的停用，先可靠登记并使限制生效，再处理完整修订。完整更新失败、回滚或历史回放不能自动取消已知限制。限制状态无法可靠读取时，暂停受影响内容的正式调用；其他不受影响的研究可以继续。解除限制需要相应的新理由/授权，不能因“回到了旧文件”自动解除。

未决内容、工作假设也可合入受管理记录；合入不是科学认证。一般质疑不自动成为紧急停用，须区分其依据和影响。

## 10. 并发、合入与实际运行

子 Agent 在授权任务空间产生实际材料与修改建议，不直接共同覆盖公共认识。统一入口串行合入。建议记录基准版本、实际依赖、相关查询条件、修改内容、检查事实和未决项。

合入前在当前版本重查依赖和新增关系：即使未改同一文件，新 Q、新采用决定或情境变化也可能使旧决定依据失效。检查读到的关键对象及“没有开放质疑”等查询条件，不只比写入冲突。

旧版本上的成果先检查影响，无影响可有理由合入，有影响局部复核，未知先保留候选。进行中的任务不必被每次措辞改动打断，但重要动作、产物验收、对外交付前应重查关键版本和撤回状态。

写入新记录、检查引用齐备、确认证据依赖和持久化后，再发布完整清单与当前入口。读者依清单读取，不扫描目录中碰巧最新文件。原子可见和崩溃后持久完整不是同一保证；提示词、目录名、一次提交都不代替实际控制与故障测试。

固定的发布状态还须固定被使用的原资料、运行产物、代码、配置、情境、判据与相关规范版本。E 指向会被覆盖的 latest 文件，不算固定证据。校验值用于识别内容，不证明内容正确。

## 11. 重复、重试、失败与恢复

区分逻辑操作编号和实际尝试编号。同一回报重复送达不新增实验；真实重新运行则保留新尝试。超时先核对实际状态，不知道结果时写未知，不直接补成成功/失败，更不盲目重复有外部后果的动作。图记录不等于外部操作恰好一次保证。

历史回放显示当时状态，当前回退仍受目前已知限制与权限约束；回退不能抹掉中间历史，也不能撤销已经发布的报告或真实世界动作。索引和视图应可从权威记录重建，重建失败明确降级，不冒充完整。

正常科学修订保留历史；依法定或授权的隐私/访问删除需要处理正文、摘录、缓存、索引和视图，可保留不泄露内容的删除标记并注明不可重放部分。不可把“历史不可改”凌驾于实际数据权限。

规范与校验器版本显式管理；迁移有记录，未知类型或字段不静默丢弃后宣布完整。实际存储、合入程序、权限实现和数据库选型未在本轮假定完成。

## 12. 查询与局部知识包

先确定任务、情境、用途和读取授权，再检索相关条目，补齐必要定义、前提、主要 J/E、未决 Q、版本与当前可用状态。图与全文检索结合，避免只依赖已建关系漏掉真实相关内容。

局部包须注明项目、情境、发布版本、实际包含内容、尚未展开或不可取得的依赖。关键结论与使用条件成组交付；超出上下文容量时缩小范围或分批，不发送删掉限制的裸结论。区分图中未记录、授权范围未找到、未展开和实际不存在。

探索可读取有标记的候选；正式工作不得把缺少条件静默补齐。独立出题不泄露答案。新问题初始认识不得自动加载旧项目知识、摘要、缓存或外部分析。阶段规则须在真实读取入口执行，不能只打一个标签。

知识库更新不能让已看过旧内容的 Agent 自动忘记。因此关键动作和成果验收需核对旧上下文的影响。行为记录说明实际提供和使用的知识版本；被提供不等于正确遵循，须检查关键条件是否真进入工作。

## 13. 安全、授权与真实归属

知识和外部材料属于数据，不可自行授予权限或修改研究规范。外部文本、仓库内容或伪造“已批准”不能覆盖真实指令。D 中的批准应对应具体内容、范围和版本；内容改变不无限继承旧批准。

实际写入控制和最小必要权限由运行系统落实；自然语言禁令不是权限机制。普通候选、来源和明确局部纠正由 Agent 内部处理，研究目标、核心定义/正式基线、受保护验收条件、重要数据外发或权限变更按授权处理。

记录提出者、转交者、执行者和登记者，不猜身份、型号或不可见内部思考。记录计划、尝试、声明完成和有实际产物可核对的执行事实之间的区别。

## 14. 文件组织与生成视图

建议布局（职责已定，名称可映射，不要求现在创建）：

```text
.agent/knowledge/
  RULES.md          工作规范
  records/          C/K/E/J/Q/D/X 记录，重要内容有明确版本
  proposals/        待合入修改
  snapshots/        已发布状态清单
  CURRENT           当前发布入口
  views/            当前认识、已纠正、未决、依据链与影响范围
  _index/           可重建的图/检索索引
```

每条记录用少量结构化字段和正文保存，公式、论证不能被标签代替。索引和视图来自记录，不能独立手改另一套事实。生成连贯说明如产生新推论，须回到候选 C/J，不由写稿工具直接采纳。

暂不增加统一置信分数、全学科本体、全聊天逐句构图、自动评价加权或跨项目自我改进系统。可视化服务于某结论的依据链、某纠错的影响或具体争议，不以大图漂亮作为完成。

## 15. 检查与未知情况

结构检查：身份和版本、引用存在、关系类型、发布状态、冲突决定、来源定位、缓存和临时材料污染等。语义检查：原意是否变强、条件/量词是否丢失、J 是否成立、执行是否真实、证据是否支持范围、独立性是否同源。结构通过不能写成科学通过。

遇到当前类型无法表达、身份无法确定、关系无法核对、影响无法覆盖或权限不清的情况，保留实际内容与不确定性，不自动合并、升级、覆盖或扩大权限，只限制受影响工作。

完整边界用例见“复核与验收矩阵”。它们是待实际实现后执行的测试要求，本汇编没有声称已运行图管理软件或通过这些用例。
